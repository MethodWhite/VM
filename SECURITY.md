# Security Policy

## Supported Versions

| Version | Supported          |
|---------|--------------------|
| develop | :white_check_mark: |
| release | :white_check_mark: |

## Reporting a Vulnerability

Las vulnerabilidades de seguridad se deben reportar privadamente.
No abras un issue público.

Contacta al equipo de seguridad en:
- **Email**: methodwhite@proton.me
- **GitHub Security**: https://github.com/MethodWhite/VM/security/advisories

Agradecemos los reportes responsables y daremos crédito público
a quien reporte vulnerabilidades validadas.
