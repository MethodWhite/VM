Standard Library Modules

Language Reference

  • Comments// line or /* block */
  • Primitivesi8, i16, i32, i64, u8, u16, u32, u64, f32, f64, bool, str
  • Functionsi32 main() { ... } — typed args and return, recursion, overloading
  • Variableslet x: i32 = 5; (immutable), let mut x: i32 = 5; (mutable)
  • Pointersunique<T> (unique ownership), shared<T> (GC-traced), borrow checking at compile time
  • Control Flowif / else, for, while, break, continue, return
  • Structsstruct Point { x: f64, y: f64 } with named fields, methods via impl
  • Enumsenum Option<T> { Some(T), None } with pattern matching via match
  • Genericsfn max<T>(a: T, b: T) -> T with trait bounds
  • Traitstrait Display { fn to_str(self) -> str; } with impl Display for T
  • Importsimport std.math.* or import std.json.JSON
  • RAIIDestructors called deterministically; unique<T> dropped at end of scope
  • GCTracing GC for shared<T> references; write barriers for cycle collection
  • Asyncasync fn / await for cooperative multitasking
  • Unsafeunsafe { } blocks for raw pointer dereference and FFI
  • FFIextern "C" fn puts(s: str) -> i32; for C ABI interop
  • Attributes#[inline], #[no_mangle], #[test] annotations
  • Operators+, -, *, /, %, &&, ||, !, ==, !=, <, >, <=, >=
